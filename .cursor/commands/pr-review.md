# Review a pull request

Read [AGENTS.md](../../AGENTS.md) for project conventions and review guidance.

1. Run `make pr-review` and read the generated `PR_REVIEW.md` for the committed changes against `main`.
2. Review the changes. Lead with actionable findings in order of severity and include file references and any verification gaps.
3. Suggest a short, imperative pull request title and a description using the headings in `AGENTS.md`.
